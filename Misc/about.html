Назначение

Показывает подробную информацию о пользователе Discord: ID, дату создания аккаунта, статус, роли и другие данные

Синтаксис

cy/about [@участник]

Параметры

  • @участник - пользователь Discord для просмотра информации. Если не указан, показывает информацию о вызвавшем команду

Особенности работы

Различия в отображении:

  • В личных сообщениях: показывает только базовую информацию (ID, создание, глобальное имя)
  • На сервере: показывает полную информацию (статус, никнейм, роли, высшую роль, дату входа)

Примеры использования

Информация о себе:

cy/about
cy/me

Информация о другом пользователе:

cy/about @User

Поля информации

На сервере:

  • ID - уникальный идентификатор пользователя
  • Упоминание - тег для упоминания
  • Создан - дата и время создания аккаунта (в формате Discord timestamp)
  • Вошёл - дата и время присоединения к серверу
  • Глобальное имя - имя пользователя Discord
  • Никнейм - отображаемое имя на сервере (если установлено)
  • Статус - текущий статус (В сети, Не беспокоить, Не активен, Не в сети)
  • Бот? - является ли пользователь ботом
  • Роли - список ролей пользователя (кроме @everyone)
  • Высшая роль - наивысшая роль по иерархии

В личных сообщениях:

  • ID
  • Упоминание
  • Дата создания аккаунта
  • Глобальное имя

Зелёный - необязательный параметр
