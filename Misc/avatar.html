Назначение

Показывает аватар указанного пользователя в полном размере. Поддерживает анимированные и статичные аватары

Синтаксис

cy/avatar [@участник]

Параметры

  • @участник - пользователь Discord для просмотра аватара. Если не указан, показывает аватар вызвавшего команду

Примеры использования

Свой аватар:

cy/avatar

Аватар другого пользователя:

cy/avatar @User

Результаты выполнения

Успех:

  • Embed-сообщение с аватаром в полном размере

Ошибки:

  • Пользователь не найден
  • Отсутствие аватара

Зелёный - необязательный параметр
