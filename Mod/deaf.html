Команда deaf

Заглушение в голосовых каналах

← На главную Синтаксис Параметры Особенности Примеры Ограничения

Назначение

Выдаёт участнику роль Deafened, которая запрещает ему говорить в голосовых каналах. Роль создаётся автоматически при первом использовании

Требуемые разрешения: Исполнителю необходимы права на управление ролями. Боту необходимы разрешения на управление ролями

Синтаксис

cy/deaf @участник [причина]

Параметры

  • @участник - пользователь Discord для заглушения
  • [причина] - причина заглушения (отображается в аудит логе)

Особенности работы

Автосоздание роли:

  • При первом использовании роль Deafened создаётся автоматически
  • Цвет роли: чёрный (colors.BLACK)
  • Причина создания: "Создано автоматически командой deaf"
  • Роль создаётся с минимальными правами

Проверки перед выполнением:

  • Проверка наличия роли Deafened у участника
  • Проверка иерархии ролей (автор vs цель)
  • Защита разработчиков бота
  • Запрет на заглушение самого себя

Примеры использования

Заглушение без причины:

cy/deaf @User

Заглушение с причиной:

cy/deaf @User Флуд в войсе

Заглушение нарушителя:

cy/deaf @User Нецензурная лексика в голосовом канале

Ограничения и важная информация

Иерархия ролей:

  • Нельзя заглушить разработчика бота
  • Нельзя заглушить участника с ролью выше вашей
  • Нельзя заглушить участника с ролью равной вашей
  • Нельзя заглушить самого себя
  • Проверки иерархии не применяются, если роль Deafened ещё не создана

Сравнение с mute:

Критерий Deaf Mute
Длительность Бессрочно
Настройка Не требуется Ручная настройка каналов
Голосовые каналы Блокирует Не блокирует

Технические детали:

  • Роль должна быть ниже роли бота в иерархии
  • Рекомендуется настроить права роли вручную после создания
  • Бот автоматически не настраивает права каналов

Результаты выполнения

Успех:

  • Embed-сообщение с полем "Заглушён" и упоминанием участника
  • Указание причины заглушения
  • Timestamp времени выполнения

Ошибки:

  • Попытка заглушения разработчика бота
  • Недостаточно прав (иерархия ролей)
  • Участник уже имеет роль Deafened
  • Попытка заглушения самого себя
  • Отсутствие прав на управление ролями
