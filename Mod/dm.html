Команда dm

Отправка анонимных сообщений в личные сообщения

← На главную Синтаксис Параметры Особенности Примеры Ограничения

Назначение

Отправляет сообщение указанному пользователю в личные сообщения от имени бота. Сообщение оформляется в embed с указанием автора

Требуемые разрешения: Исполнителю необходимы права на просмотр журнала аудита. Боту необходимо разрешение на отправку сообщений в ЛС

Синтаксис

cy/dm @участник текст

Параметры

  • @участник - пользователь Discord для отправки сообщения
  • текст - содержимое сообщения (поддерживаются ссылки, эмодзи, форматирование)

Особенности работы

Оформление сообщения:

  • Сообщение отправляется в embed-блоке
  • В качестве автора embed'а указывается отправитель (ник и аватар)
  • Текст сообщения отображается в описании embed'а

Подтверждение:

После успешной отправки бот отвечает в канал embed-сообщением с подтверждением

Примеры использования

Простое сообщение:

cy/dm @User Привет! Проверь, пожалуйста, тикет

Сообщение с форматированием:

cy/dm @User **Важно!** Обнови свои правила в <#123456789>

Уведомление о нарушении:

cy/dm @User Ваше сообщение было удалено за нарушение правил. Осторожнее

Ограничения и важная информация

Ограничения Discord:

  • Нельзя отправить сообщение пользователю, у которого закрыты ЛС
  • Нельзя отправить сообствие пользователю, который не находится на общем сервере с ботом
  • Бот должен иметь общий сервер с получателем

Ограничения команды:

  • Кулдаун: 5 секунд на пользователя
  • Сообщение не является анонимным - получатель видит, кто отправитель
  • Текст сообщения обязателен

Рекомендации:

  • Используйте для официальных уведомлений
  • Не злоупотребляйте частыми отправками
  • Убедитесь, что пользователь может получать ЛС

Результаты выполнения

Успех:

  • Embed-сообщение отправлено пользователю в ЛС
  • Embed-подтверждение в канале выполнения

Ошибки:

  • Недостаточно прав для использования команды
  • Закрытые личные сообщения у получателя
  • Отсутствие общего сервера с получателем
