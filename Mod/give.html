Команда give

Выдача ролей участникам

← На главную Синтаксис Параметры Специальные роли Примеры Ограничения

Назначение

Выдаёт одну или несколько ролей указанному участнику. Поддерживает массовую выдачу и специальные роли модерации

Требуемые разрешения: Исполнителю необходимы права на управление ролями. Боту необходимы разрешения на управление ролями

Синтаксис

cy/give @участник @роль [@роль2 @роль3 ...]

Параметры

  • @участник - пользователь Discord для выдачи ролей
  • @роль - одна или несколько ролей через пробел

Специальные роли

Роли модерации:

  • Muted - запрет на отправку сообщений
  • Deafened - запрет на речь в голосовых каналах

Эти роли создаются автоматически при первом использовании и имеют особую логику проверки

Примеры использования

Выдача одной роли:

cy/give @User @Модератор

Выдача нескольких ролей:

cy/give @User @Роль1 @Роль2 @Роль3

Выдача роли модерации:

cy/give @User Muted

Комбинированная выдача:

cy/give @User @VIP @Геймер Muted

Ограничения и важная информация

Иерархия ролей:

  • Нельзя выдать роль выше вашей роли
  • Нельзя выдать роль равную вашей роли
  • Нельзя выдать роль выше роли бота
  • Нельзя выдать роль равную роли бота
  • Нельзя выдать роль @everyone

Ограничения для специальных ролей:

  • Нельзя выдать Muted/Deafened разработчику бота
  • Нельзя выдать Muted/Deafened самому себе
  • Проверки иерархии ролей НЕ применяются к специальным ролям

Особенности работы:

  • Роли выдаются последовательно
  • При ошибке выдачи одной роли остальные продолжают выдаваться
  • Если ни одна роль не была выдана, бот сообщит об этом
  • Для ролей Muted/Deafened отправляются отдельные уведомления

Результаты выполнения

Успех:

  • Список выданных ролей с упоминаниями
  • Упоминание участника, получившего роли
  • Отдельные уведомления для специальных ролей

Ошибки:

  • Недостаточно прав (иерархия ролей)
  • Попытка выдачи @everyone
  • Попытка выдачи Muted/Deafened разработчику
  • Попытка выдачи Muted/Deafened самому себе
  • Роль выше/равна роли бота
