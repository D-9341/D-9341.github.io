Команда kick

Исключение участника с сервера

← На главную Синтаксис Параметры Проверки Примеры Рекомендации

Назначение

Исключает участника с сервера. В отличие от бана, исключённый пользователь может вернуться по приглашению

Требуемые разрешения: Исполнителю необходимы права на исключение участников. Боту необходимы разрешения на исключение участников

Синтаксис

cy/kick @участник [причина]

Параметры

  • @участник - пользователь Discord для исключения
  • [причина] - причина кика (отображается в аудит логе)

Проверки иерархии

Иерархия ролей:

  • Нельзя кикнуть разработчика бота
  • Нельзя кикнуть участника с ролью выше вашей
  • Нельзя кикнуть участника с ролью равной вашей
  • Нельзя кикнуть участника с ролью выше роли бота
  • Нельзя кикнуть участника с ролью равной роли бота
  • Нельзя кикнуть самого себя

Примеры использования

Кик без причины:

cy/kick @User

Кик с причиной:

cy/kick @User Нарушение правил

Кик за спам:

cy/kick @User Массовая рассылка

Ограничения и важная информация

Рекомендации:

  • Используйте кик при незначительных нарушениях
  • Для серьёзных нарушений используйте ban
  • Всегда указывайте причину для аудит лога

Результаты выполнения

Успех:

  • Упоминание исключённого участника
  • Указание причины кика

Ошибки:

  • Попытка кика разработчика бота
  • Недостаточно прав (иерархия ролей)
  • Попытка кика самого себя
  • Отсутствие прав на исключение у бота
  • Кулдаун команды

Зелёный - необязательный параметр
