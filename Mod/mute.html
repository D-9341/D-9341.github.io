Команда mute

Запрет на отправку сообщений в чат

← На главную Синтаксис Параметры Особенности Примеры Ограничения

Назначение

Выдаёт участнику роль Muted, которая запрещает отправлять сообщения во всех текстовых каналах. Роль создаётся автоматически при первом использовании

Требуемые разрешения: Исполнителю необходимы права на управление ролями. Боту необходимы разрешения на управление ролями

Синтаксис

cy/mute @участник [причина]

Параметры

  • @участник - пользователь Discord для мута
  • [причина] - причина мута (отображается в аудит логе)

Особенности работы

Автосоздание роли:

  • При первом использовании роль Muted создаётся автоматически
  • Цвет роли: чёрный
  • Важно: Бот НЕ настраивает права каналов автоматически!

Требуется ручная настройка:

После создания роли Muted необходимо вручную запретить ей отправку сообщений в каждом текстовом канале:

  1. Открыть настройки канала
  2. Перейти во вкладку "Разрешения"
  3. Добавить роль Muted
  4. Установить ❌ "Отправлять сообщения"

Проверки перед выполнением:

  • Проверка наличия роли Muted у участника
  • Проверка иерархии ролей (автор vs цель)
  • Защита разработчиков бота
  • Запрет на мут самого себя

Примеры использования

Мут без причины:

cy/mute @User

Мут с причиной:

cy/mute @User Флуд в общем чате

Мут за спам:

cy/mute @User Повторяющиеся сообщения

Ограничения и важная информация

Иерархия ролей:

  • Нельзя замутить разработчика бота
  • Нельзя замутить участника с ролью выше вашей
  • Нельзя замутить участника с ролью равной вашей
  • Нельзя замутить самого себя
  • Проверки иерархии применяются всегда

Важные замечания:

  • Роль Muted сама по себе НЕ запрещает писать!
  • Необходима ручная настройка прав каналов
  • Не влияет на голосовые каналы (используйте deaf)
  • Бессрочный мут (снимается только командой unmute)

Альтернативы:

  • timeout - временный мут через встроенную функцию Discord (1 час)
  • deaf - запрет речи в голосовых каналах
  • unmute - снятие мута

Результаты выполнения

Успех:

  • Указание причины мута
  • Timestamp времени выполнения

Ошибки:

  • Попытка мута разработчика бота
  • Недостаточно прав (иерархия ролей)
  • Участник уже имеет роль Muted
  • Попытка мута самого себя
  • Отсутствие прав на управление ролями
Внимание: После создания роли Muted обязательно настройте права в каналах! Без этого команда не будет работать
