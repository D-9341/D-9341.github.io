Команда unmute

Снятие запрета на отправку сообщений

← На главную Синтаксис Параметры Особенности Примеры Ограничения

Назначение

Снимает с участника роль Muted, восстанавливая возможность отправлять сообщения в чат

Требуемые разрешения: Исполнителю необходимы права на управление ролями. Боту необходимы разрешения на управление ролями
Важно: Эта команда работает ТОЛЬКО с ролью Muted. Для снятия тайм-аута используйте повторный timeout или ручное снятие

Синтаксис

cy/unmute @участник [причина]

Параметры

  • @участник - пользователь Discord для снятия мута
  • [причина] - причина снятия мута (отображается в аудит логе)

Особенности работы

Проверки перед выполнением:

  • Существует ли роль Muted на сервере?
  • Есть ли у участника роль Muted?
  • Нет проверок иерархии ролей!
  • Нет защиты разработчиков!

Отсутствие проверок:

В отличие от mute, команда unmute НЕ проверяет иерархию ролей. Это позволяет снимать мут даже с участников, у которых роль выше вашей. Разработчики бота также могут быть размучены

Примеры использования

Размут без причины:

cy/unmute @User

Размут с причиной:

cy/unmute @User Истёк срок наказания

Размут после объяснения:

cy/unmute @User Пользователь принёс извинения

Ограничения и важная информация

Возможные ошибки:

  • Роль Muted не создана - команда завершится с ошибкой
  • У участника нет роли Muted - бот сообщит об этом
  • Отсутствие прав - у бота нет прав manage_roles

Альтернативные способы:

  • cy/take @User Muted - также снимает мут, но с другим оформлением
  • Ручное снятие - через интерфейс Discord

Отличие от undeaf:

  • unmute - снимает роль Muted (текстовые каналы)
  • undeaf - снимает роль Deafened (голосовые каналы)
  • Команды независимы друг от друга

Результаты выполнения

Успех:

  • Embed-сообщение с заголовком о успешном снятии мута
  • Поле "Снял заглушение" с упоминанием модератора
  • Поле "По причине" с указанием причины
  • Timestamp времени выполнения

Ошибки:

  • Роль Muted не существует на сервере
  • Участник не имеет роли Muted
  • Отсутствие прав на управление ролями у бота
Важно: Снятие мута не удаляет роль Muted с сервера. Роль сохраняется для будущего использования
