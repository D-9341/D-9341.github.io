## Описание

**Cephalon Cy** — это мощный Discord-бот, разработанный для упрощения управления сервером и развлечения пользователей. Он предоставляет широкий набор инструментов для модерации, создания красивых embed-сообщений, генерации случайных чисел, игр (например, русская рулетка) и многого другого.

Бот написан на **Python** с использованием библиотеки **discord.py** и распространяется под лицензией **MIT**.

---

## Основные возможности

| Категория       | Описание |
|-----------------|----------|
| **Модерация**   | Бан, кик, мут, тайм-аут, очистка сообщений, выдача/забирание ролей, отправка ЛС от имени бота. |
| **Работа с сообщениями** | Отправка и редактирование сообщений с поддержкой embed, кнопок, изображений. |
| **Развлечения** | Генерация случайных чисел (roll), игра в русскую рулетку с предметами и стратегией. |
| **Информация**  | Просмотр аватара, информации о пользователе, сервере, ролях. |
| **Настройки**   | Изменение параметров игры (рулетка) через интерактивное меню. |
| **Локализация** | Поддержка нескольких языков (русский, английский, а также "особые" локали). |

## Команды

Полный список команд доступен на [сайте документации](https://d-9341.github.io/) или в боте через команду `/help`.

### Основные категории

#### `Cephalon` — базовые команды
- `/help [команда] [локаль]` — справка по командам с поддержкой локалей.
- `/botver`, `/devs`, `/info`, `/invite`, `/ping`, `/uptime` — информация о боте и разработчиках.

#### `Embeds` — работа с сообщениями
- `/say` — отправить сообщение от имени бота (с поддержкой embed, кнопок, изображений).
- `/edit` — редактировать сообщение, отправленное ботом.
- `/content` — показать полное содержимое сообщения (включая embed).

#### `Fun` — развлечения
- `/roulette [@игроки]` — русская рулетка с предметами и ИИ-дилером.
- `/settings` — настройка параметров рулетки (здоровье, патроны, сложность бота, предметы).
- `/leaderboard` — таблица лидеров по победам в рулетке.

#### `Mod` — модерация
- `/ban`, `/kick`, `/timeout` — баны, кики, тайм-ауты.
- `/mute`, `/unmute` — выдача/снятие роли Muted (текстовые каналы).
- `/deaf`, `/undeaf` — выдача/снятие роли Deafened (голосовые каналы).
- `/clear` — массовая очистка сообщений с фильтрами.
- `/give`, `/take` — выдача и забирание ролей.
- `/dm` — отправка личного сообщения пользователю от имени бота.

#### `Misc` — разное
- `/about [@участник]` — информация о пользователе.
- `/avatar [@участник]` — просмотр аватара в полном размере.
- `/serverinfo`, `/roleinfo`, `/rolemembers` — информация о сервере и ролях.
- `/coinflip` — подбросить монетку.
- `/roll [диапазон или XdY]` — генерация случайных чисел и бросок дайсов.
